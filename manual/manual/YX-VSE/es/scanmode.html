Modo de escaneo#

Modo de activación por teclas#

Pulse el botón para iniciar el escaneo y suéltelo para finalizarlo. El escaneo finaliza cuando se completa con éxito o cuando el tiempo de lectura supera el tiempo de lectura único.

Modo continuo#

El escáner funciona de forma continua. Si el escaneo es exitoso o si el tiempo de escaneo excede el tiempo de funcionamiento establecido, el escaneo actual finaliza. Si el tiempo excede el tiempo especificado, se inicia automáticamente el siguiente escaneo.

Tiempo de intervalo de lectura#

Modo de detección automática#

En el modo de detección automática, el escáner detecta la luminosidad del entorno. Cuando la luminosidad cambia, se inicia el escaneo. El escaneo finaliza cuando se completa con éxito o cuando el tiempo de escaneo supera el tiempo de funcionamiento establecido. Independientemente de si el último escaneo fue exitoso o fallido, se volverá a detectar la luminosidad del entorno.
